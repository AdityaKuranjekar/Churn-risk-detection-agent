PART 1 — LOGIN SCREEN (auth)
===============================================================================

1A. MECHANISM
  Signed session cookie via Starlette SessionMiddleware (itsdangerous).
  Single shared credential pair: APP_USERNAME / APP_PASSWORD (env).
  AUTH_DISABLED=1 fully bypasses auth (local dev + tests). Prod sets it to 0.

  requirements.txt: add `itsdangerous` (SessionMiddleware needs it).

1B. app/main.py
  from starlette.middleware.sessions import SessionMiddleware
  app.add_middleware(
      SessionMiddleware,
      secret_key=os.environ.get("SECRET_KEY", "dev-insecure-change-me"),
      session_cookie="cra_session",
      https_only=(os.getenv("COOKIE_SECURE", "0") == "1"),
      same_site="lax",
      max_age=60 * 60 * 8,          # 8h
  )
  Middleware order: SessionMiddleware BEFORE CORS is fine; StaticFiles still
  mounted LAST.

1C. app/routers/auth.py  (NEW — prefix /api, NO require_auth dependency)
  import os, secrets
  from fastapi import APIRouter, HTTPException, Request
  from pydantic import BaseModel

  router = APIRouter(prefix="/api", tags=["auth"])
  _U = os.getenv("APP_USERNAME", "admin")
  _P = os.getenv("APP_PASSWORD", "admin")
  _DISABLED = os.getenv("AUTH_DISABLED", "1") == "1"

  class LoginBody(BaseModel):
      username: str
      password: str

  @router.post("/login")
  def login(body: LoginBody, request: Request):
      ok = (secrets.compare_digest(body.username, _U)
            and secrets.compare_digest(body.password, _P))
      if not ok:
          raise HTTPException(401, "Invalid username or password")
      request.session["user"] = body.username
      return {"user": body.username}

  @router.post("/logout")
  def logout(request: Request):
      request.session.clear()
      return {"ok": True}

  @router.get("/me")
  def me(request: Request):
      if _DISABLED:
          return {"user": "dev"}
      user = request.session.get("user")
      if not user:
          raise HTTPException(401, "Not authenticated")
      return {"user": user}

  Register FIRST in main.py (before the protected routers), and it must NOT
  carry the require_auth dependency.

1D. app/deps.py  — replace the stub body
  from fastapi import Request, HTTPException
  def require_auth(request: Request) -> str:
      if os.getenv("AUTH_DISABLED", "1") == "1":
          return "dev"
      user = request.session.get("user")
      if not user:
          raise HTTPException(401, "Not authenticated")
      return user
  (All existing /api routers keep dependencies=[Depends(require_auth)].)

1E. frontend/index.html
  - App bootstrap: BEFORE routing, call GET /api/me (credentials:"include").
      200 -> store user, render normal app (renderDashboard / route()).
      401 -> render LOGIN CARD, stop.
  - LOGIN CARD (reuse design tokens; centered, max-width 360px):
      logo mark + "Churn Risk Agent"
      <label>Username</label> <input id=u autocomplete=username>
      <label>Password</label> <input id=p type=password
                                     autocomplete=current-password>
      <button>Sign in</button>   (primary, --accent)
      <p class=err> (hidden until failure) </p>
      Submit on Enter. No "register", no "forgot password", no OAuth.
  - Submit handler:
      POST /api/login {username,password}  (credentials:"include")
        200 -> location.hash = "#/"; render app
        401 -> show err "Invalid username or password"; shake input (subtle,
               respect prefers-reduced-motion)
  - EVERY api() fetch: add  credentials: "include"  (cookie must ride along).
  - Global 401 handler in api(): if any protected call returns 401 mid-
    session -> clear state, render login card.
  - Top-bar menu: add "Sign out" -> POST /api/logout -> render login card.

2C. Dockerfile  (repo root)
  FROM python:3.12-slim

  # HF Spaces best practice: non-root user, writable home
  RUN useradd -m -u 1000 user
  ENV HOME=/home/user PATH=/home/user/.local/bin:$PATH \
      PYTHONUNBUFFERED=1 PORT=7860
  WORKDIR /home/user/app

  # system deps (xgboost/llvmlite/shap need libgomp; build-essential for wheels)
  RUN apt-get update && apt-get install -y --no-install-recommends \
        libgomp1 && rm -rf /var/lib/apt/lists/*

  COPY --chown=user:user requirements.txt .
  RUN pip install --no-cache-dir --user -r requirements.txt

  COPY --chown=user:user . .
  RUN chmod +x start.sh

  USER user
  EXPOSE 7860
  CMD ["bash", "start.sh"]
